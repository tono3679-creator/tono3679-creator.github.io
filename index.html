Delivery Manager

配送業務のすべてを、ひとつの画面で。

  • 従業員5〜30名の配送会社向け。案件・配車・ドライバー・車両・荷主・売上を一元管理
  • 配車ボードはドラッグで割り当て。ドライバーはスマートフォンから配送ステータスを更新
  • 訪問者ごとに専用のデモ会社（案件 約6,000件）をその場で作成。権限は PostgreSQL の RLS で分離
  • Next.js 16
  • React 19
  • TypeScript
  • PostgreSQL / Neon
  • Tailwind CSS
  • Leaflet
  • Playwright

建設DX Manager

案件から利益まで、工事ごとに見える化。

  • 中小規模の建設会社・設備工事会社向けの業務管理システム
  • 「案件 → 現場作業 → 日報 → 勤怠 → 原価 → 売上・利益」を案件IDを中心に一元管理
  • 管理者・現場責任者・一般スタッフの3つの役割。現場スタッフはスマートフォンで日報入力
  • Next.js 16
  • TypeScript
  • Supabase
  • PostgreSQL
  • Vercel
